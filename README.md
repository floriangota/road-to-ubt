# Road to UBT — cyber prep planner

A 13-month study planner (September 2026 → October 2027) for going from medical high school to a cybersecurity bachelor at UBT: digital foundations, CCNA1, Linux + first Python, Matura mode, and a summer sprint.

Single `index.html`, no build step, no dependencies. Progress saves in the browser via `localStorage`, so it lives on whatever device you tick the boxes on.

**Run it:** open `index.html`, or host it with GitHub Pages (Settings → Pages → deploy from `main`, root).
